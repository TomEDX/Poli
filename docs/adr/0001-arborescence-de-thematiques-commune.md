# Une seule arborescence de thématiques pour tous les modules

Le quiz, le comparateur de programmes et le module législatif rangent tous leur contenu dans la même arborescence à deux niveaux exactement (thématique, sous-thématique), gérée par les éditeurs. Une liste par module aurait été plus libre, mais une liste commune permet de relier une question du quiz aux extraits de programme et aux scrutins du même sujet, et évite de maintenir plusieurs classements qui divergent.
